# EDA_FactoresRiesgoDepre

Acerca del conjunto de datos
Este conjunto de datos contiene información de 200 personas y se recopiló para analizar los factores psicológicos y de estilo de vida asociados a la depresión. Las variables incluyen el nivel de estrés percibido, el apoyo social, la autoestima, las horas de sueño por noche, los antecedentes familiares de depresión, el consumo de cafeína, el sexo y la edad. La variable dependiente (depresión) se ha codificado de forma dicotómica (0 = No, 1 = Sí). Este conjunto de datos está destinado a utilizarse en análisis de regresión logística binaria para identificar factores de riesgo y de protección relacionados con la salud mental.
